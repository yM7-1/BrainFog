## 1. 核心规则（已定）

### 1.1 卡牌可见性（核心系统）
- 所有卡牌**实例**初始为**黑雾**（插画、名称、描述、费用全不可见）。
- **打出一次后揭示**：本局内该卡永久显示真牌面（0.02 第 6 条；无手动匹配）。
- **按卡牌定义记忆**（**实机调整 2026-09-19**，原为按实例）：打出任一副本后，该卡名的**所有副本**（含之后获得的）均揭示；升级同样按定义揭示（0.03 a 的按定义延伸）；**单局记忆**，新局重置；随存档持久化。
- **悬停/选中未知牌**：仅显示必要的卡牌边框，边框内为黑雾（无任何识别信息）（0.03 b）。
- **升级一律揭示真牌面**，即使该实例从未打出（0.03 a）。
- **获得场景**（卡牌奖励/事件/商店）：牌面相关仅显示**稀有度边框**；升级版卡显示 **"+" 标记**（0.03 h）。**实机调整（2026-09-19）**：不在任何玩家牌堆的卡（事件选牌/通用选牌界面）一律按获得场景处理；奖励界面"右键查看升级"的升级预览不构成揭示、牌面保持遮蔽；**奖励界面右键打开的查看屏即使该卡已揭示也按获得场景显示**（第二轮修复）。
- 卡名在所有文本处（事件/奖励/商店/日志）隐藏未知（0.02 第 2 条）。
- 费用随牌面隐藏；"费用区可见"仅指**能量球**（0.02 第 2 条）。
- **牌堆界面**（抽/弃/消耗）：已揭示的牌显示**已知真牌面**，未知仍黑雾（0.03 g）。
- **图鉴（CardLibrary）不遮蔽**（0.03 j）。
- **卡牌查看/升级界面**的附加信息栏（关键词描述，如中毒/虚弱）**50% 乱码**（实机调整 2026-09-19；2026-09-20 起每次启动重新随机，同次启动内稳定）。
- **揭示后的卡面**：插画可见，但卡面所有文字（名称/描述/类型/费用/星级）**85% 乱码**（实机调整 2026-09-19；图鉴仍保持可读；2026-09-20 起每次启动重新随机）。**乱码在源头写入**（`MegaLabel/MegaRichTextLabel.SetTextAutoSize` 前缀），避免打牌时文本重复重排造成卡顿（2026-09-20）。

### 1.2 状态快照
- 血量、金币显示为**旧快照**，不实时更新（不知道自己快死=设计意图）。**实机调整（2026-09-19）**：战斗内角色血条（数字+血条填充）不显示真实血量，仅顶栏保留旧快照；格挡 UI 不受影响。顶栏血量以**灰色**呈现并标注"上次休息时的状态"，附提示"该状态并非当前真实状态，请在火堆休息获得最新状态信息"。
- **刷新点**：休息（HP+金币）、商店/事件**扣金币后**（金币）（0.02 第 3 条）。
- **不刷新**：金币**获得**（战斗/宝箱/事件加钱）、HP**治疗**（事件/遗物）（0.03 c）。
- **濒危提示**：真实 HP < 15% 最大生命 → 角色模型边框发红 + 状态栏"濒危：我感觉自己快死了"；基于**真实 HP**，**战斗内外均提示**（0.03 d）。

### 1.3 战斗内
- 玩家角色可见；己方召唤物完整可见。**实机调整（2026-09-19）**：取消玩家视野圆形遮罩（原"周围一圈"），战斗场景全可见——仅敌人被呼吸框遮蔽。
- 敌人模型不可见，以**呼吸源**（长方形框）跟随原呼吸动画呈现；敌方召唤物同规则；**敌人名字隐藏**（实机调整 2026-09-19：悬停不显示名字，血条/能力仍可读）。
- 敌我受击效果保留；**实机调整（2026-09-21）**：受击/治疗/格挡**数字改为乱码**（原"含伤害数字"保留可读，撤销）。
- 敌人意图（攻击数值/类型）**仅每场战斗第 1 回合显示**；第 2 回合起**完全无图标**；中途召唤的新敌人**不显示意图**；多阶段 Boss（如实验体）**仅第一阶段的第一回合**显示（0.03 f）。
- 能量球可见；手牌未知=黑雾（悬停规则见 1.1）。
- 抽/弃/消耗牌堆见 1.1；药水使用选项正常，插画仅可见轮廓。

### 1.4 战斗外
- 遗物：不可见，描述界面黑雾；**被动提示正常**；**获得场景**（奖励/商店/宝箱/事件）同样不可见——悬停提示抑制、奖励行名称替换为"未知遗物"（实机调整 2026-09-19）；**Boss 遗物三选一可见**（0.03 i）。
- 药水：插画仅轮廓；使用/选择正常；**名称与描述文字 50% 乱码**（实机调整 2026-09-19；2026-09-20 起每次启动重新随机，同次启动内一致）。
- 地图：当前节点可见；已走过的路径/图例可见；下一层可选路径/图例可见；**画线工具禁用**；**Boss 点显示"?"**（字号略小于原 Boss 图标，节点可点击；悬停不显示 Boss 信息；实机调整 2026-09-19 第四轮）。
- **顶栏阶段 Boss 图标**：完全移除（不渲染、不可聚焦、悬停"boss，整片地区最强大的敌人"不显示；实机调整 2026-09-19）。
- 战斗开始横幅、阶段切换横幅（"阶段3 荣耀"）、房间结束"前进"按钮、火堆选项文字乱码（默认 60%；实机调整 2026-09-19）。
- 先古之民（含建筑师）对话与选项 90% 乱码、商人对话 90% 乱码（实机调整 2026-09-19）。
- 事件文本：**全部文本**按该事件总文字 **75% 比例模糊乱码**；同次启动内**不重掷**（同一事件每次打开一致），**每次启动游戏重新随机**（2026-09-20 修订）（0.03 e）。
- 黑雾总范围（0.02 第 8 条）：即"卡面不可见"+上述具体条目，不额外做全屏雾化。
- **界面文字**（实机调整 2026-09-19）：标题界面与暂停菜单的选项文字 75% 乱码（设置按钮保留可读，设置界面本身不受影响；**每次启动重新随机**，2026-09-20）。
- **顶栏 Boss**：不再显示当前阶段末尾要面对的 Boss 图标（实机调整 2026-09-19；悬停提示同样不显示）。

## 2. 技术要点（可行性已核对）

- ~~**实例身份**：`CardModel.Props` GUID 方案~~（**已弃用 2026-09-19**）：揭示改为按卡牌定义（`ModelId`，如 `cards.STRIKE`）后不再需要实例身份；随存档只保存已揭示定义键集合。
- **打出钩子**：`CardModel.OnPlayWrapper`（`CardModel.cs:1858`）。
- **升级揭示钩子**：卡牌升级入口（锻造/事件/遗物）需定位（实现时补）。
- **事件模糊实现**：按事件实例哈希固定种子，选取 75% 字符替换为乱码；注意 BBCode/富文本标签不参与替换，选项保持可点。
- **遮蔽 UI 点位**：`NCard`（`_portrait/_frame/_titleLabel/_descriptionLabel`，`NCard.cs:508-518`）、`NCardPreviewContainer`、`NCardRewardSelectionScreen`、`NCardLibrary`、`NTopBar`（Hp/Gold）、`NRelic`/`NInspectRelicScreen`、`NPotion`、`NMapScreen`（节点/路径/图例/画线）、`NIntent`、`NCreature`（Body 为 Spine 2D 骨骼动画，呼吸源可绑定动画相位）、牌堆界面、Boss 遗物选择界面。
- **持久化**：揭示集合存于本局（RitsuLib `RunSavedDataStore` 或 `Props`），读档恢复；新局重置。
- **版本策略**：只支持固定游戏版本（0.111.0），补丁目标清单化 + 版本适配层。

## 4. MVP 分期建议

- **Phase 1（稳定核心）**：卡牌黑雾 + 打出揭示 + 升级揭示 + 按定义持久化 + 获得场景（稀有度边框/加号）+ 悬停边框+黑雾 + 牌堆已知显示 + 状态快照 + 濒危提示 + 单人守卫。
- **Phase 2**：敌人呼吸源（长方形框）+ 受击保留（含伤害数字）+ 意图仅首回合 + 药水轮廓。
- **Phase 3**：地图迷雾 + 画线禁用 + 遗物隐藏（Boss 遗物例外）+ 事件 75% 模糊。
