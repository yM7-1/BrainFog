## 1. 核心规则（已定）

### 1.1 卡牌可见性（核心系统，0.02 第 1/2/5/6/7 条）
- 所有卡牌**实例**初始为**黑雾**（整张牌面不可见：插画、名称、描述、费用；仅"获得场景"例外，见下）。
- **打出一次后揭示**：该实例在战斗中被打出一次后，本局内永久显示真牌面（0.02 第 6 条；取代原"手动匹配"方案）。
- **按实例记忆**：其他同名副本不共享揭示状态（例：一张"铁斩波"揭示后，之后获得的"铁斩波"仍是黑雾）；**单局记忆**，新局全部重置。
- **获得场景**（卡牌奖励、事件、商店购买）：牌面相关仅显示**稀有度边框**（0.02 第 5 条）。
- **升级揭示**：锻造/事件/遗物升级后显示正确牌面（0.01 3.2 + 0.02 第 7 条；具体语义见开放问题 a）。
- 卡名在所有文本处（事件/奖励/商店/日志）一律隐藏未知（0.02 第 2 条）。
- 费用：卡牌费用随牌面隐藏；"费用区可见"仅指**能量球**（0.02 第 2 条）。

### 1.2 状态快照（0.02 第 3 条）
- 血量、金币显示为**旧快照**，不实时更新（不知道自己快死=设计意图）。
- 刷新点：**休息**（HP+金币）、**商店/事件扣金币后**（金币）。
- 濒危提示：真实 HP < 15% 最大生命 → 角色模型边框发红 + 状态栏"濒危：我感觉自己快死了"。

### 1.3 战斗内（0.01 4 + 0.02 第 4/9/10 条）
- 玩家角色可见（模型+周围一圈）；己方召唤物完整可见。
- 敌人模型不可见，以**呼吸源**（可用长方形框）跟随原呼吸动画呈现；敌方召唤物同规则。
- 敌我受击效果保留，**含伤害数字**。
- 敌人意图（攻击数值/类型）**仅第一回合显示**。
- 能量球可见；手牌未知=黑雾；抽牌堆/弃牌堆/消耗牌堆打开=黑雾。
- 药水使用选项正常，插画仅可见轮廓。

### 1.4 战斗外（0.01 3 + 0.02 第 9 条）
- 遗物不可见，描述界面黑雾；**遗物被动提示正常**。
- 药水插画仅轮廓（使用/选择正常）。
- 地图：当前节点可见；已走过的路径/图例可见；下一层可选路径/图例可见；**画线工具禁用**。
- 事件文本：约 **75% 模糊乱码**（细则见开放问题 e）。
- 黑雾总范围（0.02 第 8 条）：即"卡面不可见"+"上述具体条目"，不额外做全屏雾化。

### 1.5 平台与依赖（0.02 第 10 条）
- **仅单人**：检测到联机（`RunManager.cs:516` `IsMultiplayer`）时禁用或提示。
- 依赖：**仅 RitsuLib 0.6.2**（BaseLib 不使用）。
- 开发策略：**先做一版稳定的，再逐步完善**（MVP 分期见 §4）。

## 2. 技术要点（可行性已核对）

- **实例身份**：游戏 `SerializableCard` 无实例 ID（`SavedProperties` 结构见 `Core/Saves/Runs/SerializableCard.cs`）；但 `CardModel.Props`（`SavedProperties`）随存档**逐实例**序列化并回填（`CardModel.cs:2235`/`:2249`），可用 `BlindSpire.` 前缀的 GUID 作为实例 ID，实现按实例、跨存读档的单局记忆。
- **打出钩子**：`CardModel.OnPlayWrapper`（`CardModel.cs:1858`）。
- **遮蔽 UI 点位**：`NCard`（`_portrait/_frame/_titleLabel/_descriptionLabel`，`NCard.cs:508-518`）、`NCardPreviewContainer`、`NCardRewardSelectionScreen`、`NCardLibrary`、`NTopBar`（Hp/Gold）、`NRelic`/`NInspectRelicScreen`、`NPotion`、`NMapScreen`（节点/路径/图例）、`NIntent`、`NCreature`（Body 为 Spine 2D 骨骼动画，呼吸源可绑定动画相位）。
- **持久化**：揭示集合存于本局（RitsuLib `RunSavedDataStore` 或 `Props`），读档恢复；新局重置。
- **版本策略**：只支持固定游戏版本（0.111.0），补丁目标清单化 + 版本适配层。

## 4. MVP 分期建议

- **Phase 1（稳定核心）**：卡牌黑雾 + 打出揭示 + 按实例持久化 + 获得场景稀有度边框 + 状态快照 + 濒危提示 + 单人守卫。
- **Phase 2**：敌人呼吸源/长方形框 + 受击保留 + 意图仅第一回合 + 牌堆黑雾。
- **Phase 3**：地图迷雾 + 画线禁用 + 药水轮廓 + 遗物隐藏 + 事件 75% 模糊 + 图鉴处理。
