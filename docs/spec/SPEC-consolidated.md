# BlindSpire 合并规格（0.01 + 0.02 + 0.03，v0.3）

> 状态：**开放问题全部确认（0.03），规格冻结，可进入实现设计。**
> 原始文本：`Blind0.01.txt`、`Blind0.02.txt`、`Blind0.03.txt`；评审：`Blind0.01-review.md`。
> 技术依据：`.refs/sts2-v0.111.0/src`（游戏 v0.111.0）。
> 定位：面向**渴望加强难度的高阶玩家**（0.03 补充）。

## 1. 核心规则（已定）

### 1.1 卡牌可见性（核心系统）
- 所有卡牌**实例**初始为**黑雾**（插画、名称、描述、费用全不可见）。
- **打出一次后揭示**：该实例本局内永久显示真牌面（0.02 第 6 条；无手动匹配）。
- **按实例记忆**：同名副本不共享（例：一张"铁斩波"揭示后，之后获得的"铁斩波"仍是黑雾）；**单局记忆**，新局重置；随存档持久化。
- **悬停/选中未知牌**：仅显示必要的卡牌边框，边框内为黑雾（无任何识别信息）（0.03 b）。
- **升级一律揭示真牌面**，即使该实例从未打出（0.03 a）。
- **获得场景**（卡牌奖励/事件/商店）：牌面相关仅显示**稀有度边框**；升级版卡显示 **"+" 标记**（0.03 h）。
- 卡名在所有文本处（事件/奖励/商店/日志）隐藏未知（0.02 第 2 条）。
- 费用随牌面隐藏；"费用区可见"仅指**能量球**（0.02 第 2 条）。
- **牌堆界面**（抽/弃/消耗）：已揭示的牌显示**已知真牌面**，未知仍黑雾（0.03 g）。
- **图鉴（CardLibrary）不遮蔽**（0.03 j）。

### 1.2 状态快照
- 血量、金币显示为**旧快照**，不实时更新（不知道自己快死=设计意图）。
- **刷新点**：休息（HP+金币）、商店/事件**扣金币后**（金币）（0.02 第 3 条）。
- **不刷新**：金币**获得**（战斗/宝箱/事件加钱）、HP**治疗**（事件/遗物）（0.03 c）。
- **濒危提示**：真实 HP < 15% 最大生命 → 角色模型边框发红 + 状态栏"濒危：我感觉自己快死了"；基于**真实 HP**，**战斗内外均提示**（0.03 d）。

### 1.3 战斗内
- 玩家角色可见（模型+周围一圈）；己方召唤物完整可见。
- 敌人模型不可见，以**呼吸源**（长方形框）跟随原呼吸动画呈现；敌方召唤物同规则。
- 敌我受击效果保留，**含伤害数字**。
- 敌人意图（攻击数值/类型）**仅每场战斗第 1 回合显示**；第 2 回合起**完全无图标**；中途召唤的新敌人**不显示意图**；多阶段 Boss（如实验体）**仅第一阶段的第一回合**显示（0.03 f）。
- 能量球可见；手牌未知=黑雾（悬停规则见 1.1）。
- 抽/弃/消耗牌堆见 1.1；药水使用选项正常，插画仅可见轮廓。

### 1.4 战斗外
- 遗物：不可见，描述界面黑雾；**被动提示正常**；**获得场景**（奖励/商店/事件）同样不可见；**Boss 遗物三选一可见**（0.03 i）。
- 药水：插画仅轮廓；使用/选择正常。
- 地图：当前节点可见；已走过的路径/图例可见；下一层可选路径/图例可见；**画线工具禁用**。
- 事件文本：**全部文本**按该事件总文字 **75% 比例模糊乱码**，**固定不重掷**（同一事件每次打开一致）（0.03 e）。
- 黑雾总范围（0.02 第 8 条）：即"卡面不可见"+上述具体条目，不额外做全屏雾化。

### 1.5 平台与依赖
- **仅单人**：检测到联机（`RunManager.cs:516` `IsMultiplayer`）时禁用或提示。
- 依赖：**仅 RitsuLib 0.6.2**（BaseLib 不使用）。
- 开发策略：**先做一版稳定的，再逐步完善**（MVP 分期见 §4）。

## 2. 技术要点（可行性已核对）

- **实例身份**：游戏 `SerializableCard` 无实例 ID；但 `CardModel.Props`（`SavedProperties`）随存档**逐实例**序列化并回填（`CardModel.cs:2235`/`:2249`），可用 `BlindSpire.` 前缀 GUID 作实例 ID，实现按实例、跨存读档的单局记忆。
- **打出钩子**：`CardModel.OnPlayWrapper`（`CardModel.cs:1858`）。
- **升级揭示钩子**：卡牌升级入口（锻造/事件/遗物）需定位（实现时补）。
- **事件模糊实现**：按事件实例哈希固定种子，选取 75% 字符替换为乱码；注意 BBCode/富文本标签不参与替换，选项保持可点。
- **遮蔽 UI 点位**：`NCard`（`_portrait/_frame/_titleLabel/_descriptionLabel`，`NCard.cs:508-518`）、`NCardPreviewContainer`、`NCardRewardSelectionScreen`、`NCardLibrary`、`NTopBar`（Hp/Gold）、`NRelic`/`NInspectRelicScreen`、`NPotion`、`NMapScreen`（节点/路径/图例/画线）、`NIntent`、`NCreature`（Body 为 Spine 2D 骨骼动画，呼吸源可绑定动画相位）、牌堆界面、Boss 遗物选择界面。
- **持久化**：揭示集合存于本局（RitsuLib `RunSavedDataStore` 或 `Props`），读档恢复；新局重置。
- **版本策略**：只支持固定游戏版本（0.111.0），补丁目标清单化 + 版本适配层。

## 4. MVP 分期建议

- **Phase 1（稳定核心）**：卡牌黑雾 + 打出揭示 + 升级揭示 + 按实例持久化 + 获得场景（稀有度边框/加号）+ 悬停边框+黑雾 + 牌堆已知显示 + 状态快照 + 濒危提示 + 单人守卫。
- **Phase 2**：敌人呼吸源（长方形框）+ 受击保留（含伤害数字）+ 意图仅首回合 + 药水轮廓。
- **Phase 3**：地图迷雾 + 画线禁用 + 遗物隐藏（Boss 遗物例外）+ 事件 75% 模糊。
