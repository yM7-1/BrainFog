[h1]脑雾尖塔 BrainFog[/h1]

大部分尖塔文字将被替换为乱码，可在内置修改器中使部分游戏内容恢复正常。

[h2]认知修改器[/h2]
主标题界面与对局内均可操作（可拖动/收起/缩进屏幕边缘，可一键重置为默认）：
[list]
[*][b]文字[/b]：乱码百分比 0%–100% 自由调节；乱码模式：固定混乱（重进不变）/ 混乱混乱（每次重进重新随机）
[*][b]认知[/b]：卡牌奖励揭示（不揭示 / 随机揭示1-3张 / 奖励全部揭示）；商店与事件卡面揭示开关；卡牌记忆四模式；记忆消逝开关；卡牌计数器
[*][b]感知[/b]：血量/金币失忆模式；血量数/金币数恢复正常显示；显示已拥有遗物；显示地图所有路线；敌人模型可见；敌人意图（不可见 / 仅第一回合 / 全部可见）
[/list]

[h2]卡牌记忆四模式[/h2]
[list]
[*][b]通晓万物[/b]：全部卡牌直接可见
[*][b]好记性[/b]：打出/升级一次即永久记住，同名卡在所有奖励/商店/事件中也显示真牌面
[*][b]坏记性[/b]（默认）：每张卡上手 n 次未打出就会忘记（n 默认 2、可调）；打出重置计数；新获得的牌先认得，即将失忆的手牌会变暗提醒
[*][b]歪比巴卜[/b]：卡牌永不揭示
[/list]

开局牌组视为记得（好记性/坏记性）。[b]记忆消逝[/b]（开关，默认开）：战斗结束时仍未揭示的牌会从卡组中移除（歪比巴卜模式不受影响，无保底）。[b]卡牌计数器[/b]（开关，默认关）：记录每张牌（同名按加入顺序编号，如「打击1」）本局打出的次数，右上角显示可收起的排行榜。

[h2]核心效果[/h2]
[list]
[*][b]卡牌失认[/b]：开局牌组视为记得；默认打过的牌才认得；奖励与选牌界面默认只显示稀有度
[*][b]文字失读[/b]：事件、菜单、提示、卡面与对话全部乱码（图鉴与设置除外），乱码程度可调
[*][b]记忆失真[/b]：血量与金币默认实时但同样是乱码；可切换失忆模式停留在「上次休息时」，或开启「血量数/金币数恢复正常显示」让数值可读
[*][b]世界模糊[/b]：敌人只剩呼吸方框、名字隐藏（可开启「敌人模型可见」）；遗物不可见、药水只剩轮廓、地图迷雾、Boss 信息隐藏；受击/治疗数字乱码
[/list]

依赖 STS2 v0.111.0 与 RitsuLib 0.6.2；仅单人；卸载即恢复原版。

[h1]BrainFog[/h1]

Most text in the Spire is replaced with garbled static — use the built-in modifier to restore parts of the game.

[h2]Cognition Modifier[/h2]
Available on the main menu and in-run (draggable, collapsible, dockable; one-click reset to defaults):
[list]
[*][b]Text[/b]: unified blur percentage 0%–100%; blur mode: fixed chaos / re-rolled on every launch
[*][b]Cognition[/b]: card reward reveal (none / random 1-3 / all); shop & event card faces on/off; four card-memory modes; memory fade; play counter
[*][b]Perception[/b]: HP/gold amnesia mode; readable HP/gold numbers; show owned relics; show all map routes; visible enemy models; enemy intents (hidden / first round only / always)
[/list]

[h2]Card memory modes[/h2]
[list]
[*][b]Omniscience[/b]: every card is visible
[*][b]Good memory[/b]: playing/upgrading a card remembers it for the run — including its copies in rewards, shops and events
[*][b]Bad memory[/b] (default): a card is forgotten after n unplayed draws (n defaults to 2, adjustable); playing resets the counter; newly acquired cards start known, and a hand card about to be forgotten dims
[*][b]Nonsense[/b]: cards are never revealed
[/list]

The starting deck counts as known (good/bad memory). [b]Memory fade[/b] (on by default): cards still unrevealed at the end of a combat are removed from the deck (nonsense mode exempt; no floor). [b]Play counter[/b] (off by default): counts plays per copy (same-name copies numbered by joining order, e.g. Strike1) and shows a collapsible top-right leaderboard.

[h2]Core effects[/h2]
[list]
[*][b]Card agnosia[/b]: the starting deck is remembered; by default only cards you have played are recognized; rewards/selection show rarity only
[*][b]Text alexia[/b]: events, menus, prompts, card text and dialogue are garbled (compendium and settings stay readable); the level is adjustable
[*][b]Faulty memory[/b]: HP and gold are live by default but garbled; switch on amnesia mode to freeze them at your last rest, or turn on readable HP/gold numbers
[*][b]Blurred world[/b]: enemies are breathing boxes with hidden names; relics invisible, potions outlined, map fogged, boss info hidden; damage/heal numbers garbled
[/list]

Requires STS2 v0.111.0 + RitsuLib 0.6.2. Single-player only; uninstall restores everything.

GitHub: https://github.com/yM7-1/BrainFog
